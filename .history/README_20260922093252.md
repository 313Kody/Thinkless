# Thinkless

Thinkless est une plateforme web de gestion de matchs, ligues sportives et ligues e-sport, développée dans le cadre du BTS SIO. Elle permet à un utilisateur de créer un compte, gérer son profil, rejoindre des sports ou jeux, organiser des matchs publics ou privés, créer des ligues et participer à des compétitions structurées.

## Stack technique

- Node.js 20
- Express 5
- MySQL 8
- JWT
- bcryptjs
- multer
- HTML + JavaScript vanilla
- Tailwind via CDN
- Docker Compose

## Fonctionnalités principales

### Authentification et profil

- inscription et connexion via JWT
- récupération du profil utilisateur connecté
- mise à jour du pseudo, de la localisation et du mot de passe
- ajout / modification / suppression des sports et jeux de l'utilisateur
- gestion de l'équipe e-sport de l'utilisateur

### Matchs sportifs

- création de matchs publics et privés
- génération d'un code d'accès pour les matchs privés
- participation à un match via code ou via la liste des matchs
- affichage du détail d'un match et de ses participants
- validation et retrait des joueurs
- gestion de résultat pour un match
- gestion de l'équipe dans les formats d'équipe

### E-sport

- création d'équipes e-sport avec capitaine et membres
- envoi de demandes d'adhésion
- acceptation ou refus d'une demande
- création de ligues e-sport
- rejoindre une ligue publique ou privée
- création de matchs e-sport
- convocations de joueurs par le capitaine
- enregistrement du résultat d'un match e-sport
- classement par jeu et par ligue

### Ligues sportives

- création de ligues publiques et privées
- accès à un code d'invitation pour les ligues privées
- consultation des détails d'une ligue
- classement par joueur ou par équipe selon le contexte
- affichage des matchs et des équipes associées

### Ligues privées avec équipes pré-créées

Pour les ligues de sport en équipe, l'application supporte :

- définition du nombre d'équipes
- définition du nombre de places par équipe
- pré-création des équipes au moment de la création de la ligue
- création rapide d'un match de ligue à partir des équipes déjà présentes

Pour les sports solo, la configuration est simplifiée :

- `nb_equipe = 1`
- `slots_par_equipe = 1`
- classement conservé par joueur

## Base de données

Le schéma principal est dans `database/thinkless_db.sql`.

Le serveur se connecte à la base avec les variables suivantes définies dans le fichier `.env`.

## Configuration de l'environnement

Créer un fichier `.env` à la racine du projet avec le contenu suivant :

```env
DB_HOST=thinkless-db
DB_PORT=3306
DB_USER=root
DB_PASS=root
DB_NAME=thinkless_db
PORT=3000
JWT_SECRET=thinkless_secret_key
```

## Lancer le projet

### Prérequis

- Docker
- Docker Compose
- réseau Docker `f1_network`
- Node.js 20 (si on veut lancer en local sans Docker)

### Créer le réseau Docker

```bash
docker network create f1_network
```

### Démarrer l'application avec Docker

Depuis la racine du projet :

```bash
docker-compose up -d
```

Services exposés :

- application web : http://localhost:81
- MySQL : localhost:3307

### Arrêter l'application

```bash
docker-compose down
```

### Lancer en local sans Docker

```bash
npm install
npm run dev
```

Le serveur écoute sur le port défini dans `.env` (par défaut `3000`).

## Remarques utiles

- les matchs créés depuis une ligue ne remontent pas dans la liste globale des matchs
- les matchs privés restent visibles par leur créateur et leurs participants
- le classement dépend du type de ligue et de la présence ou non d'équipes pré-créées
- la table `Ligue` est partagée entre sport et e-sport selon la colonne utilisée : `sport_id` ou `jeu_id`
- l'API publie aussi une route simple de santé : `GET /ping`
